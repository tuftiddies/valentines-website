# Valentine's Day Website

A retro-styled interactive Valentine's Day web page.

## Features

- Old school computer aesthetic with monospace fonts, chunky borders, and pixel-style shadows
- Floating heart animations
- Interactive dialog boxes with Yes/No options
- Confetti and glittery "YAY" celebration on Yes
- "Say sike rn" dialog with a "try again" button on No
- Congratulations dialog after the celebration
- Sparkle effect on mouse movement

## How to Run

1. Clone the repository
2. Start a local server:
   ```
   python3 -m http.server 8000
   ```
3. Open http://localhost:8000 in your browser

## Tech Stack

- HTML
- CSS
- JavaScript
